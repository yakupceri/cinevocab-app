# CineVocab Mobile

Android app for [CineVocab](https://cinevocab.up.railway.app): paste a YouTube link and get the new words from its subtitles, skipping the ones you have already seen in earlier videos.

- **Video:** reads the subtitles on the phone, sends only a word list to the server, and adds the words you pick to your account.
- **Words:** your list, with search and "I know it".
- **Practice:** a short multiple-choice quiz with spaced repetition.
- **Me:** streak, word count, XP, app language (English / Turkish).

Built with plain HTML/CSS/JS wrapped by Capacitor. It talks to the same FastAPI backend as the CineVocab website and Chrome extension.

## Run it

```
npm install
npx cap sync
npx cap open android
```

Then press Run in Android Studio. The Gradle JDK must be 21.

## Layout

- `www/index.html`, `www/app.css`: screens and styles
- `www/app.js`: login, API calls, home feed, games (practice, daily challenge, live duel, leagues)
- `www/config.js`: public server address (no secrets)
- `www/yt.js`: subtitle reading and word extraction
- `www/lang.js`: common-word lists shared with the extension
- `android/`: native project generated by Capacitor
